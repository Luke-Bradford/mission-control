# Current HUD — desktop research gallery

Current code at `6b6b2135`, 1 November 2026. Every image uses 1× device scale. Saved free-form content and repo/loop/account identities, dynamic object keys, paths, branches and other-project references are replaced before rendering; originals remain private. These are sanitised current-screen illustrations, not proposed mockups. Geometry can differ where replacement text wraps. Numeric measurements of these captures are in [measurements.json](measurements.json); the research separately identifies its original-content sample.

All browser writes and external requests were blocked. QA send-back uses an acceptance response fixture. Final onboarding mode/account uses simulated successful check responses: no check or onboarding POST reached the server. All other controls were opened without submitting them.
