# telemetry

The numbers behind the Telemetry page and the start gates: `telemetry.ts` (the page's panels), `metrics.ts`
(the crew metrics view), `machine-capacity.ts` (the machine-capacity admission check), `pace.ts` (the pace
settings and start check), `prompt-cost.ts` (what a seat's prompt costs) and `audit-improvements.ts`
(the audit thresholds and suggested improvements). The routes in `../api.ts` serve them.
